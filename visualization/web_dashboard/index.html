⚡ Data Architecture & Pipeline Execution Flow

1. Multi-Source Raw Ingestion

Extracting raw structured datasets (25 Store Hubs across India, Product Catalog, Customer Profiles, Orders, Items, Inventory) and 50,000 semi-structured JSON clickstream records.

2. Data Staging & Cleaning

Performing deduplication, timestamp casting, payment method normalization (UPI, NetBanking, COD), and loading staging schemas.

3. Star Schema Data Warehouse Modeling

Building dimension tables (`dim_store`, `dim_product`, `dim_customer`, `dim_date`) and fact tables (`fact_sales`, `fact_inventory_snapshot`, `fact_web_events`) with surrogate keys.

4. Automated Data Quality Audit

Running 13 automated checks: null integrity, primary key uniqueness, non-negative value bounds, and foreign key referential integrity (100% Passed).

5. Data Mart Export & Power BI Integration

Materializing analytical data marts into Parquet & CSV formats for BI reporting.
